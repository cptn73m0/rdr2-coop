# Дорожная карта — RDR2 CO-OP

Кооператив для одиночного сюжета RDR2. Дорожная карта показывает этапы,
порядок работ и текущий прогресс. Отмечаем галочками по мере выполнения.

- [x] Сборка `.asi`, совместимость с билдом 1.0.1491.50

## Архитектурная заметка

- Каждый клиент гоняет свою копию мира; сюжетные миссии не синхронизируются
  (движок не даёт API), поэтому кооп — «наблюдатель», а не полное совместное
  прохождение миссий.
- Связь по интернету, как договорено, — через WireGuard/туннель между
  машинами (NAT обходится виртуальной сетью).
