# Инструкции для агентов в репозитории rdr2-coop

## Обязательный навык: ub-mode

При ЛЮБОМ написании или изменении кода в этом репозитории **всегда** применяй навык
`ub-mode` (см. `.agents/skills/ub-mode/SKILL.md`; в сессии DSH он доступен как скилл
`ub-mode`). Он обязателен и не требует отдельного вызова пользователем.

Каждая единица работы:
1. **First make it work** — smallest edit; сначала форма данных; где возможен честный
   тест — сначала падающий тест; убирай сложность до того, как добавлять.
2. **Then make it right** — root cause, а не заплатка; функции под CRAP ~10; убери
   дублирование; удали мёртвый код; рефакторинг докажи тем, что поведение не изменилось
   (сборка + тесты).
3. **Practice** — короткий лог действий и причин в отчёте; маленькие упорядоченные
   коммиты (зачем/что/как проверено); финальный push; чистый worktree.

## Правила проекта

- Proof gate для любой единицы: `cmake --build build` + `powershell -ExecutionPolicy
  Bypass -File scripts\ci.ps1` (интеграция 41/41 + C++ тесты). Для поведения в игре —
  запись в `dist\<tag>` snapshot.
- Протокол не меняется без отдельной задачи и парного деплоя ASI+server.
- Канонические `build/` и `build-server/` — только Lead; WIP собирать в своих каталогах.
- Сервер запускать только в видимом окне.
- Работать по непересекающимся write scopes; чужие файлы не править.
