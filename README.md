# RDR2 CO-OP — кооперативный мод для одиночного сюжета

Кооперативный мод для **Red Dead Redemption 2** (Story Mode): два игрока играют
по сети, каждый проходит сюжет у себя, а второй игрок виден в мире как
**пед-призрак** — с синхронизацией движения, поворота, одежды, оружия, лошади,
действий, смерти/возрождения, а также общего времени и погоды.

Связь — через лёгкий сервер-релей (`rdr2_coop_server.exe`). Обмен бинарный,
кадр состояния 88 байт, частота **60 Гц**.

## Статус

Проверено в игре двумя игроками на билде **1.0.1491.50**:

### Сеть и мир
- ✅ Сервер-релей: JOIN / FRAME / LEAVE, таблица игроков, персистентность
  последней позиции (`players.txt`), лог подключений с IP.
- ✅ Кадр состояния **60 Гц** (~5 КБ/с на клиента).
- ✅ Общее время и погода от хоста (первый подключившийся).
- ✅ Смерть и возрождение: пед-призрак умирает только вместе с оригиналом
  (труп и снаряжение остаются), после возрождения — `RESURRECT_PED` и надпись.

### Пед-призрак
- ✅ Спавн по модели персонажа из кадра, обвязка рендера
  (mission entity + random variation + visible).
- ✅ Позиция и поворот: движение задачей по навмешу (шаг/бег по скорости),
  мёртвая зона поворота, плавная интерполяция.
- ✅ Особые состояния: ragdoll, укрытие, плавание, лазание, прыжок, падение.
- ✅ Действия: сценарий (еда/питьё/курение), сидение, пьян.
- ✅ Имя над головой и метка на карте/мини-карте (обновляется по позиции).
- ✅ **Одежда**: надетые shop-предметы передаются отдельным сообщением и
  применяются к педу (сброс слоёв + наряд, без «просвечивания» старой одежды).
- ✅ **Оружие**: модель выдаётся и берётся в руку (`GIVE_WEAPON_TO_PED` +
  `SET_CURRENT_PED_WEAPON`), доставание, прицеливание, перезарядка, стрельба
  настоящими выстрелами (звук, вспышка, отдача). Событие выстрела — отдельный
  пакет с точкой попадания, поэтому выстрелы не теряются.
- ✅ **Точка прицела** передаётся в кадре: пед целится и стреляет туда же,
  куда целится игрок (а не «вперёд по heading»).
- ✅ **Лошадь**: модель из кадра, появление рядом с педом, анимации
  `TASK_MOUNT_ANIMAL` / `TASK_DISMOUNT_ANIMAL`, движение по навмешу, удаление
  после спешивания; коллизия с локальным игроком/его лошадью отключается.

### Инфраструктура
- ✅ Конфиг `rdr2-coop.ini` рядом с `.asi`: адрес/порт сервера, ник, модель.
- ✅ Клиентские пакеты в `dist/` (хук + ASI-лоадер + плагин + скрипты + ini).
- ✅ Лог плагина `scripts\rdr2-coop.log`, лог сервера — в окне консоли.

## Известные ограничения

- Сюжетные миссии не синхронизируются — движок не даёт API; кооп — «второй
  игрок в мире», а не совместное прохождение миссий.
- Оверлеи внешности (усы, борода, причёска) не передаются: у движка нет
  геттеров их состояния.
- Стрельба педа-призрака наносит реальный урон (вставать на линии огня
  не стоит).
- Снаряжение лошади (седло/поклажа) синхронизируется не полностью:
  мета-наряд лошади у сюжетных моделей равен 0.
- Надетые на оригинале аксессуары могут появляться у педа не всегда точно
  (список shop-предметов включает не только одежду).

## Требования

- **Red Dead Redemption 2** для PC, билд **1.0.1491.50** (только Story Mode).
- **ScriptHookRDR2.dll** (V2 2.0 / Alexander Blade) рядом с `RDR2.exe`.
- **ASI-лоадер** (`dinput8.dll` / `dsound.dll`) в папке игры.
- Компилятор: **Visual Studio 2019 Build Tools** (MSVC x64) + CMake.

## Сборка

Клиент (ASI-плагин):

```
cmake -S . -B build -G "Visual Studio 16 2019" -A x64
cmake --build build --config Release
```

Сервер:

```
cmake -S . -B build-server -G "Visual Studio 16 2019" -A x64
cmake --build build-server --config Release
```

Результат: `build/Release/rdr2_coop.asi` и `build-server/Release/rdr2_coop_server.exe`.

## Установка клиента

1. `rdr2_coop.asi` — в `...\Red Dead Redemption 2\scripts\` (папку создать).
2. `rdr2-coop.ini` — рядом с `.asi` (в той же `scripts\`).
3. `ScriptHookRDR2.dll` и ASI-лоадер (`dinput8.dll`) — в корень игры.
4. Запустить игру → Сюжет. Лог: `scripts\rdr2-coop.log`.

```ini
# rdr2-coop.ini
server_host = 192.168.1.103   ; ПК с сервером
server_port = 7777
player_name = Player2
ped_model   = 0xCF7E73BE      ; запасная модель, пока не пришла модель персонажа
```

> Без `ScriptHookRDR2.dll` плагин не загрузится — в логе будет
> `ScriptHookRDR2.dll not found`.

## Запуск сервера

```
E:\rdr2-coop\run_server.bat 7777
```

или вручную:

```
rdr2_coop_server.exe 7777
```

Сервер хранит последние позиции игроков в `players.txt`, пишет лог в консоль.
Порт должен быть доступен клиентам (локальная сеть или туннель).

## Протокол

Все сообщения: `u32 length | u8 type | payload`.

| type | сообщение      | направление            | payload |
|------|----------------|------------------------|---------|
| 0x01 | Join           | клиент → сервер        | имя, модель |
| 0x02 | JoinOk         | сервер → клиент        | sid, сохранённая позиция, isHost |
| 0x03 | PlayerJoined   | сервер → остальные     | имя, модель, позиция |
| 0x04 | Frame          | клиент → сервер → все  | `FramePayload` (88 байт) |
| 0x05 | Leave          | клиент → сервер        | — |
| 0x06 | PlayerLeft     | сервер → остальные     | имя |
| 0x07 | Died           | клиент → сервер → все  | имя |
| 0x08 | WorldState     | хост → сервер → все    | время, погода |
| 0x09 | Outfit         | клиент → сервер → все  | модель + компоненты одежды |
| 0x0A | Respawned      | клиент → сервер → все  | имя |
| 0x0B | Shot           | клиент → сервер → все  | точка попадания (x,y,z) |

`FramePayload` (88 байт): позиция (x,y,z), heading, `move`, `state`, `flags`,
`action`, здоровье, точка прицела (aimX/Y/Z + дистанция), хэш оружия, `seq`,
резерв (модель лошади, мета-наряд игрока, модель персонажа), наряд лошади.

## Как устроено

- `src/main.cpp` — `DllMain` + цикл скрипта (`ScriptMain`).
- `src/script_hook.cpp/h` — резолв экспортов `ScriptHookRDR2.dll` по PE-таблице
  (проприетарный SDK не нужен).
- `src/native_call.h` — вызов нативов + маршаллинг `Vec3`.
- `src/natives.h` — проверенные хэши нативов (сверены с `rdr2-runtime-scripthook`
  и `rdr3-nativedb-data`).
- `src/coop.cpp` — вся игровая логика: спавн и рендер педа, движение задачи,
  одежда, оружие, лошадь, смерть/возрождение, время/погода, кадры 60 Гц.
- `src/config.cpp`, `src/persist.cpp`, `src/log.cpp` — конфиг, персистентность,
  логгер.
- `net/protocol.h` — типы сообщений и структуры пакетов.
- `net/client.cpp`, `net/frame.cpp`, `net/socket.cpp` — сетевой клиент,
  сборка/разбор кадров, сокеты.
- `server/server.cpp` — релей, таблица игроков, `players.txt`.
- `dist/` — готовые клиентские пакеты и ini.
- `third_party/` — справочные исходники (ScriptHook runtime, nativedb, каталог
  одежды), используются только для сверки хэшей и параметров.

## Практические заметки

- Человеческий пед **не рендерится** без обвязки
  `SET_ENTITY_AS_MISSION_ENTITY` + `SET_PED_RANDOM_COMPONENT_VARIATION` +
  `SET_ENTITY_VISIBLE`.
- `RESET_PED_COMPONENTS` ломает рендер тела (остаются только одёжки) — вместо
  него используется random variation + применение наряда в том же тике.
- Число параметров нативов важно: `GET_CURRENT_PED_WEAPON` принимает 5
  аргументов, `GIVE_WEAPON_TO_PED` — 13; при меньшем числе движок читает мусор.
- Короткие события (выстрел) нельзя опрашивать по кадру — только отдельным
  сообщением/latch.
