# Поезда/состав — статус R&D и план v19

**Статус (26.10.2026):** старый R&D proxy-attach **устарел** (deprecated), не
развивается и не включается в рабочие сборки (`world_trains = 0`). Текущая
репликация транспорта — **E3d-a vehicles-only** (`world_vehicles=1`,
`npc_vehicle_radius=80`): обычные машины/повозки/лодки как `WorldSnapshot`
Vehicle-прокси, без водителей/пассажиров (E3d-c) и без поездов (E3d-b).
Поезда — отдельный следующий этап: **mission-train в protocol v19** (в работе
у net-review), а не покадровые вагоны-прокси.

## Почему proxy-attach устарел

Старая схема `world_trains=1` слала каждый вагон как обычный `Vehicle`-прокси
и на госте привязывала их к локомотиву через `ATTACH_ENTITY_TO_ENTITY`:

- нет состава/порядка/сцепки, рельсов, скорости/направления и станций;
- прокси двигались скачками 10 Гц, без физики; возможны рассинхрон и отрывы;
- вагоны занимали общий бюджет 16 Vehicle и вытесняли машины/повозки;
- не было машиниста/пассажиров/дверей; визуальная целостность не
  гарантировалась.

Этот путь оставлен только как исторический код; новые фичи на него не
опираются. `world_trains=1` не использовать для приёмки/публичной сборки.

## План v19: mission-train

1. **Protocol v19:** отдельные сообщения `VehicleOccupants 0x21` и
   `TrainSnapshotV2 0x22` (в работе у net-review; текущий протокол — v18).
2. **TrainSnapshotV2:** engineNetId/model, позиция/heading, direction,
   speed, station/rail state, упорядоченный список вагонов (netId + offset +
   model), а не набор безымянных Vehicle.
3. **Хост:** для mission-train брать реальный состав через
   `_GET_TRAIN_CARRIAGE_TRAILER_NUMBER`/`GET_TRAIN_CARRIAGE`;
   `VehicleOccupants` — машинист/пассажиры (после E3d-c).
4. **Гость:** создавать mission-train/цепочку вагонов одним составом
   (`CREATE_MISSION_TRAIN`-подобный путь), двигать по рельсам/станциям;
   fallback — без частичной привязки отдельных прокси.
5. **Приёмка:** поезд едет по рельсам, вагоны в правильном порядке, скорость/
   направление совпадают, пассажиры не дублируются; при неудаче
   `world_trains=0` и поезда остаются вне репликации.

## Ограничения текущего v18

- Поезда не реплицируются; `world_trains` — устаревший R&D-флаг.
- Машины/повозки E3d-a — только `WorldSnapshot`-прокси без физики; водители/
  пассажиры не реплицируются до E3d-c.
- `WorldSnapshot` vehicle-only: до 16 машин в радиусе 80 м вокруг обоих
  игроков; пустые снапшоты удаляют прокси.
- Точная репликация рельсового движения без v19 невозможна; не включать
  proxy-attach в публичные сборки.

## Как проверить после v19

1. Оба ПК: `world_sync=0`, `npc_actor=1`, `world_vehicles=1`,
   `npc_vehicle_radius=80`, `npc_visitor_vehicles=1`; поезд — по E3d-b.
2. Хост садится/едет на mission-train; гость видит состав, вагоны не
   отрываются, скорость/направление совпадают.
3. В логах: `world: vehicles send n=`, `world: vehicle spawn/despawn`,
   `train:`/`TrainSnapshotV2` (v19), `train_debug=1` для offset/rails.
4. При рассинхроне — `world_trains=0`, сохранить логи и вернуться к v18.
