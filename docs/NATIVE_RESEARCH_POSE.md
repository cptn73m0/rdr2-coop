# Разведка: позы/анимации педа-призрака (crouch/stealth/clipset)

Цель: понять, почему пед-призрак не повторяет некоторые позы оригинала
(приседание, крадущийся режим, нюансы доставания/убирания оружия), и что
можно перенять из подхода RedM/CitizenFX, не влезая в версионный реверс.

## Что уже синхронизируется (факт из src/coop.cpp)

- Оружие: доставание/убирание — `kFlagWeaponDrawn`/`kFlagWeaponChanging`
  → `StartGhostWeaponDraw`/`StartGhostWeaponHolster`.
- Бой: прицел/стрельба/перезарядка — `Action::Aiming/Shooting/Reloading`.
- Действия: сценарий/сидение/пьян — `Action::InScenario/Sitting/Drunk`
  + покрытие v2 `ActionStatePayload` (Cover/Carry/Drag/Hogtie/Loot/Fishing).
- **Отсутствует:** приседание (crouch/duck), крадущийся режим (stealth),
  специфичные movement-clipsets (боевая стойка, пригнувшись).

## Что перенимаем из RedM (архитектурно, не код)

RedM/CitizenFX реплицирует позу глубже enum-списка: оно оперирует
конкретными xешами анимаций/клипсетов (`SET_PED_MOVEMENT_CLIPSET`) + желаемый
move-blend + флаги синхронизированных сцен (`NETWORK_*_SYNCHRONISED_SCENE`).
Наша аналогия: вместо «список из N Action» реплицировать наблюдаемые
состояния через конкретные нативы (crouch/stealth/aim-pose), где они
доступны в ScriptHook 1.0.1491.50. Прямое копирование CitizenFX-вызовов
невозможно (другой рантайм/билд), но *список что реплицировать* — полезен.

## Нативная база (локальная)

`research/rdr3-nativedb-data/natives.json` (2.4 МБ) — полная база RDR3-нативов
(c хешами, сигнатурами, минимальным build). Источник для разведки новых поз.

## Найденные нативы для приседания/скрытности (build 1207; у нас 1.0.1491.50)

| Хеш | Имя | Роль |
|---|---|---|
| 0xD5FE956C70FF370B | `GET_PED_CROUCH_MOVEMENT(ped) -> BOOL` | читать: приседает ли пед |
| 0x7DE9692C6F64CFE8 | `_SET_PED_CROUCH_MOVEMENT(ped, state, p2, immediately)` | применять: присесть/встать |
| 0x7C2AC9CA66575FBF | `GET_PED_STEALTH_MOVEMENT(ped) -> BOOL` | читать: крадётся ли |
| 0x88CBB5CEB96B7BD2 | `SET_PED_STEALTH_MOVEMENT(ped, toggle, p2, p3)` | применять (NB: «Not implemented» в базе) |
| 0xA14B5FBF986BAC23 | `TASK_DUCK(ped, p1)` | задача присесть |
| 0x97B0DB5B4AA74E77 | `RESET_PED_WEAPON_MOVEMENT_CLIPSET(ped)` | сброс боевого клипсета |

Все эти хеши ОТСУТСТВУЮТ в `src/natives.h` — их надо добавить и проверить
в игре (некоторые могут быть nullsub/«Not implemented» в 1491.50).

## Ограничение (уже зафиксировано в docs/UB_MODE.md)

Публичный SDK не отдаёт текущий клип/фазу/бленды AnimGraph; запись позы
скелета невозможна. Реплицируем только наблюдаемые высокоуровневые состояния
через нативы. Точная клип-в-клип синхронизация — версионный реверс (не цель).

## План внедрения приседания (следующий шаг)

1. Добавить хеши в `src/natives.h`.
2. Отправитель: читать `GET_PED_CROUCH_MOVEMENT` (+ stealth) в `SendLocalPlayerFrame`,
   запаковать в свободный бит `flags` (напр. kFlagCrouching) — БЕЗ изменения
   размера кадра (протокол не трогаем).
3. Получатель: `_SET_PED_CROUCH_MOVEMENT` педу-призраку при смене флага.
4. Проверка в игре (2-ПК): присесть/встать → пед повторяет; красться → повторяет.
