# Двух-ПК тест-план RDR2 CO-OP

Проверки, которые нужно прогнать, когда будут доступны оба ПК. Пока игра
недоступна, headless-часть покрыта `tests/integration_server.py`.

## 0. Подготовка

1. Одинаковые сборки на обоих ПК:
   - `rdr2_coop.asi` — из `dist\spike1-test` (или шары);
   - `rdr2_coop_server.exe` — из `dist\spike1-test`;
   - протокол должен совпадать (сервер сам отклоняет старую версию).
2. Сделать бэкап сейвов гостя (и хоста, если тестируете миссии).
3. Закрыть игру и старый сервер.
4. Запустить сервер: `run_server.bat` (порт 7777) или
   `dist\spike1-test\run_server_v4.bat` (актуальный exe; имя файла историческое).
5. Запустить игру на обоих ПК.

## 1. INI-флаги (на обоих ПК, кроме credit)

| Флаг | По умолчанию | Что включает |
|---|---|---|
| `world_sync` | 0 | NPC/транспорт/mission-объекты (P1) |
| `action_sync` | 0 | сценарии/укрытие/переноска/лутание (P2) |
| `vehicle_sync` | 0 | посадка удалённого игрока в транспорт |
| `mission_sync` | 0 | активная миссия + завершения/рейтинг |
| `mission_credit` | 0 | запись зачёта миссии в **свой** сейв гостя |
| `save_backup` | 1 | бэкап сейва перед первым зачётом |
| `mission_reward_log` | 1 | dry-run лог каталога наград (без применения) |
| `world_trains` | 0 | R&D: поезда/вагоны в WorldSnapshot (экспериментально) |
| `world_mission_entities` | 0 | P1 safe: реплицировать mission-peds/objects |
| `world_suppress_ambient` | 0 | P1 safe: глушить ambient людей (без животных/транспорта) |
| `vehicle_crew` | 0 | P1: синхронизировать водителя/пассажиров (seat) |
| `world_debug` | 0 | Диагностика: логировать позиции прокси world_sync |
| `train_debug` | 0 | R&D: подробный лог offset/attach вагонов |

Рекомендуемый первый прогон: `world_sync=1`, `action_sync=1`,
`vehicle_sync=1`, `mission_sync=1`, `mission_credit=0` (только события).

## 2. Базовое подключение

- [ ] Хост подключается первым → `[HOST]`, гость вторым → `[GUEST]`.
- [ ] Третий игрок получает отказ `ServerFull`.
- [ ] Повторный ник получает `NameTaken`.
- [ ] Отключение гостя убирает педа/метку.
- [ ] Обрыв сети у гостя: субтитр «Connection lost — reconnecting...»,
      автопереподключение с backoff, после JOIN пед возвращается.
- [ ] Выход хоста: у гостя субтитр «You are now HOST», он может продолжить
      как хост; новый игрок подключается к нему, snapshot принимается.
- [ ] Перезаход восстанавливает последнюю позицию (`players.txt`).
- [ ] RTT/джиттер отображается в HUD.

## 3. Игрок, движение, анимации

- [ ] Ходьба/бег/галоп; без телепортов лошади при отставании.
- [ ] Покой без «танцев» (гистерезис 1.5/2.5 м).
- [ ] Выстрелы: пистолет с магазином — проигрываются все.
- [ ] Перезарядка, прицел, укрытие (вход/выход).
- [ ] Одежда без просвечивающей кожи (96 категорий).
- [ ] Смерть → труп; возрождение.

## 4. P1: мир

- [ ] Педы ходят/бегут у гостя (не телепортятся).
- [ ] Дилижанс/повозка/лодка/трамвай появляются у гостя; поезда пропускаются
      (`trains_skipped` в логе).
- [ ] Миссионные объекты видны (`obj=` в логе).
- [ ] Лог хоста: `world: host snapshot ... ped=... veh=... obj=...`.
- [ ] Лог гостя: `world: guest proxies=...`.

## 5. P2: действия и транспорт

- [ ] Сценарий: сесть/закурить/поесть → гость повторяет.
- [ ] Укрытие: вход/выход, стрельба из укрытия.
- [ ] Переноска/лутание: **хост** поднимает тело/лутает → гость видит;
      затем гость → хост (нужен `world_sync`).
- [ ] Посадка в транспорт: хост в дилижансе → гость видит транспорт и
      призрака на месте; при выходе прокси исчезает.

## 6. P3: миссии

- [ ] Хост начинает миссию из каталога → у гостя субтитр
      `Host mission: <название>`; в логе `mission: host ACTIVE`.
- [ ] Барьер: гость получает Offer → в логе `barrier: offer ... accepted=1`,
      хост — `barrier: guest ready -> start window open`; у гостя субтитр
      `START NOW: <название>`; гость вручную начинает ту же миссию → хост
      видит `barrier: guest STARTED`; если не успел за 45 с — `abort timeout`.
- [ ] Гость с недоступной миссией получает `accepted=0` и Abort.
- [ ] Гость вручную начинает ту же миссию у себя (автостарта нет).
- [ ] Хост завершает миссию → у гостя `mission: host event ...`.
- [ ] `mission_credit=0`: в сейв гостя ничего не пишется.
- [ ] `mission_reward_log=1`: в логе гостя виден `mission: reward plan ...`
      (dry-run, нативы не вызываются) для миссий из каталога 17/23.
- [ ] `mission_credit=1` + `save_backup=1`: гость видит
      `mission: save backup OK` → `CREDITED to own save`; сохранить вручную;
      проверить журнал. При ошибке — restore из
      `Documents\rdr2-coop-saves\<timestamp>`:
      ```powershell
      # dry-run (ничего не пишет), затем -Force
      powershell -File scripts\restore_saves.ps1 -BackupDir "C:\Users\<you>\Documents\rdr2-coop-saves\<timestamp>"
      powershell -File scripts\restore_saves.ps1 -BackupDir "..." -Force
      ```
- [ ] **Не включать** `mission_credit`, если прогресс сильно разный.

## 7. Сбор логов и откат

- Клиент: `rdr2-coop.log` рядом с игрой/ASI.
- Сервер: `server_console.log` в рабочей папке.
- Откат:
  - `.asi` — из `scripts\rdr2_coop.asi.bak-*`;
  - INI — `rdr2-coop.ini.bak-*`;
  - сервер — старый exe из `build-server`/`dist`;
  - сейвы — `rdr2-coop-saves\<timestamp>`.

## 8. Известные ограничения

- Миссии не проходятся совместно в одном инстансе: каждый проходит свою копию.
- Автостарта миссии у гостя нет; барьер только информационный.
- Точные клипы AnimGraph/AnimScene не передаются; NPC-прокси — только
  idle/walk/run.
- Транспорт — визуальный прокси без физики/салона; поезда пока не реплицируются.
- Награды миссий (деньги/оружие) пока не переносятся автоматически.
